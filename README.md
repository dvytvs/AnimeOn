# AnimeOn

AnimeOn is a Tauri-based application for watching anime from animeon.cc or its mirror site.

## Features

- Automatically detects and uses the available AnimeOn website (main or mirror)
- Google login integration through default browser
- Cross-platform support (Windows, Linux)

## Building

To build the application:

```bash
# Install dependencies
npm install

# Build for development
npm run dev

# Build for production
npm run build
```

## Requirements

- Rust 1.70+
- Node.js 16+
- Tauri CLI

# AnimeOn

AnimeOn — это приложение, созданное на базе Tauri, предназначенное для просмотра аниме с сайта animeon.cc или его зеркала.

## Возможности

- Автоматическое обнаружение и использование доступного домена сайта AnimeOn (основного или зеркала)
- Интеграция входа через Google (с использованием браузера по умолчанию)
- Кроссплатформенная поддержка (Windows, Linux)

## Сборка

Для сборки приложения выполните следующие команды:

```bash
# Установка зависимостей
npm install

# Сборка для разработки
npm run dev

# Сборка для выпуска (production)
npm run build
```

## Системные требования

- Rust 1.70+
- Node.js 16+
- Tauri CLI
